Open-source projects

Jisko publishes a few open-source tools, most under the MIT licence.

MIPS Runner · 2026

VS Code extension to run and debug MIPS assembly. It needs neither MARS nor Java: the SPIM simulator runs as WebAssembly inside the editor. Execution steps through instruction by instruction, with registers, memory and pointers.

VS Code Marketplace · Source code

RWKV Factory · 2026

RWKV models that estimate the probability of remembering a card at the moment of review, for spaced-repetition software. They are trained on the public anki-revlogs-10k dataset (about 727 million reviews). Training became 6.7 times faster, with bit-identical results. Six models were released in November 2026.

Overview and dashboards · Source code (anki-rwkv)

ッツ Ebook Reader, Anki fork · 2025–2026

Fork of ッツ Ebook Reader, ttu-ttu's online e-book reader built for Japanese. The fork colours each word by the state of its Anki card: mature, young, new, due, or not in any deck.

Image: sample rebuilt with the fork's colours.

Source code · Original project

CardScheduler · 2025–2026

Anki add-on for Japanese vocabulary. It orders new cards by what they unlock: knowing one kanji reading makes other words easier. The score uses familiarity with each reading, word complexity and sentence cards. The add-on then repositions new cards in that order.
