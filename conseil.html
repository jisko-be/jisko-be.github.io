Conseil

Jonathan Schoreels travaille en mission longue, le plus souvent au sein de l'équipe du client. Missions fréquentes :

  • l'audit d'une application ou d'une plateforme : architecture, qualité du code, maintenabilité, sécurité ;
  • les problèmes techniques persistants, y compris en démontant un composant ancien ou tiers pour comprendre son fonctionnement ;
  • l'encadrement d'une équipe de développeurs : pratiques de travail, choix techniques, lien avec les autres équipes et la direction ;
  • l'outillage autour du code : intégration et déploiement continus, supervision, alertes.

Il prototype vite pour valider une idée, puis approfondit les performances et l'optimisation.

Technologies : Java et Spring Boot, Apache Camel, messagerie JMS et AMQP, Docker Swarm et Kubernetes, AWS et Azure. Il utilise aussi Claude Code et Codex pour aller plus vite et vérifier davantage.

Missions récentes

Il travaille dans le public et le privé.

  • depuis 2024 architecte technique dans le secteur public, sur des projets critiques ;
  • 2021–2024 team lead d'une équipe de huit développeurs chez un éditeur international d'information professionnelle ;
  • 2019–2021 technical lead Java chez un groupe belge de l'énergie et des télécommunications.
